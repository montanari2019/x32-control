# Discuss

Use inside Specify when gray areas need user decisions.

Capture in `context.md`:

- Question.
- Options considered.
- User decision.
- Rationale.
- Impact on requirements/design/tasks.

Rules:

- Ask focused questions.
- Prefer 1-3 questions at a time.
- Do not proceed on risky assumptions when behavior, data ownership, or user workflow is unclear.
