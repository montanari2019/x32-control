# Session Handoff

Use when pausing or resuming work.

Pause workflow:

1. Update global and local `STATE.md`.
2. Record current branch, changed files, tests run, and unfinished work.
3. Record next recommended action.
4. Note blockers and decisions needed from the user.

Resume workflow:

1. Read global `STATE.md`.
2. Identify target domain/feature.
3. Read local `STATE.md`.
4. Read active spec/design/tasks only as needed.
5. Confirm or infer the next executable step.
