# Validate

Use after implementation or for explicit verification/UAT requests.

Validation levels:

- Static: typecheck, lint, formatting.
- Unit: focused tests.
- Integration: services, state flow, navigation, persistence.
- Manual/UAT: user-facing workflows and acceptance criteria.

Report:

- What was validated.
- Commands run.
- Pass/fail status.
- Gaps or untested risks.
- Requirement IDs covered.

Interactive UAT is used for complex user-facing behavior.
