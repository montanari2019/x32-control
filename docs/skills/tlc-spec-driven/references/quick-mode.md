# Quick Mode

Use for small tasks: bug fixes, config changes, text edits, or <=3 files.

Workflow:

1. Describe expected change in one sentence.
2. Implement directly.
3. Verify with the cheapest relevant check.
4. Record a short summary.

Do not create full spec/design/tasks unless scope expands during implementation.

Escalate to Specify when:

- more than 3 files are needed;
- behavior is ambiguous;
- there is user-facing workflow risk;
- architectural decisions appear.
