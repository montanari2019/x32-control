# Roadmap

Use when planning milestones or sequencing features.

Structure:

- Current objective.
- Milestones.
- Feature list with status.
- Dependencies.
- Risks.
- Deferred ideas.

Rules:

- Keep roadmap outcome-focused, not task-focused.
- Link roadmap items to feature specs when they exist.
- Move cross-cutting risks to `.specs/project/STATE.md`.
