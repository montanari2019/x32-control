# Project Init

Use when starting a new project or formalizing an existing one.

Steps:

1. Create `.specs/project/` if missing.
2. Create `PROJECT.md` with vision, users, goals, non-goals, constraints, stack, and success criteria.
3. Create `ROADMAP.md` with milestones and feature candidates.
4. Create or update `STATE.md` with workspace type, preferences, and open questions.
5. Keep content short enough to load at session start.

Verification:

- Project purpose is clear.
- Roadmap has ordered, scoped items.
- Workspace type and spec placement preference are recorded.
