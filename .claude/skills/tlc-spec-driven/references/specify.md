# Specify

Use to define what needs to be built.

For Medium scope, create a brief `spec.md`:

- Problem.
- Goal.
- Requirements.
- Acceptance criteria.
- Out of scope.

For Large/Complex scope, use traceable IDs:

```txt
REQ-001: ...
REQ-002: ...
```

Rules:

- Requirements describe behavior, not implementation.
- Acceptance criteria must be observable.
- Ambiguities trigger Discuss.
- Every later task should trace back to one or more requirement IDs.
