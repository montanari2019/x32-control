# Concerns

Use to record technical debt, risk, blockers, and fragile areas.

Each entry:

```txt
## [short title]
Area:
Evidence:
Impact:
Suggested action:
Status:
```

Rules:

- Evidence must point to code, logs, tests, or reproducible behavior.
- Keep cross-feature concerns in `.specs/codebase/CONCERNS.md`.
- Keep feature-local blockers in local `STATE.md`.
