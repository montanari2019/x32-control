# State Management

Use `STATE.md` as persistent memory across sessions.

Global `STATE.md` sections:

- Workspace Type.
- Preferences.
- Cross-Feature Decisions.
- Architectural Blockers.
- Deferred Ideas.
- Session Notes.

Local `STATE.md` sections:

- Current Status.
- Decisions.
- Blockers.
- Task Progress.
- Lessons Learned.

Rules:

- Date important entries.
- Prefer concise bullets.
- Move resolved blockers into a short resolution note instead of deleting useful history.
