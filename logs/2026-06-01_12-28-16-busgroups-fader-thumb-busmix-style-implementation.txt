# BusGroups Fader Thumb BusMix Style Implementation

Date: 2026-06-01

## Context

Implemented `src/features/busGroups/.specs/feature/fader-thumb-busmix-style`.

Goal: make BusGroups Bus Master and MCA fader thumbs use the same physical fader cap style as BusMix, while preserving the current master/MCA color identity.

## Changes

- Added `src/shared/components/FaderThumb.tsx`.
  - Visual-only shared fader cap.
  - Preserves BusMix dimensions: `32 x 52`, radius `14`.
  - Preserves BusMix layer structure: shades, top light, bottom shade, four grooves, and center line.
  - Keeps BusMix pressed feedback values.
- Added `src/shared/utils/faderThumbPalette.ts`.
  - Defines neutral BusMix palette.
  - Adds deterministic color palette derivation for master/MCA thumbs.
- Added `__tests__/shared/utils/faderThumbPalette.test.ts`.
- Migrated `src/features/busMix/components/VerticalFader.tsx`.
  - Keeps animation, gestures, fader math, linked pressed feedback, rail handling, zero mark, and dB scale in place.
  - Uses shared neutral `FaderThumb`.
- Updated `src/features/busGroups/components/VerticalGroupFader.tsx`.
  - Uses shared `FADER_THUMB_METRICS.height` for fader travel/hit testing.
  - Uses shared `FaderThumb` with master/MCA-colored palettes.
  - Adds pressed feedback state.
  - Keeps master meter rail/fill and dB scale structure unchanged.
