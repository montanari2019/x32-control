## Technical Research Summary

- Existing BusMix meter fix docs confirm Tacimix must request X32 meter streams via `/meters` with a string argument such as `/meters/1`, not by sending raw `/meters/1`.
- Existing BusMix decoder already handles the X32 blob payload shape used in the project: 4-byte little-endian count header followed by little-endian float values.
- X32/M32 meter references indicate `/meters/2` is the Mix Bus meters stream and its first 16 floats are BUS master level meters.
- `/meters/5` is surface VU-meter oriented and parameterized by surface group/bank, so it is not the first-choice source for a fixed selected BUS master in Tacimix.
- The implementation should decode selected BUS meter value as index `busId - 1`.
