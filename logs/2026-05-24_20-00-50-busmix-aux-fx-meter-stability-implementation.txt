BUSMIX AUX/FX METER STABILITY IMPLEMENTATION

Contexto
- O usuario pediu implementar a spec src/features/busMix/.specs/feature/aux-fx-meter-stability seguindo docs/skills/tlc-spec-driven.
- Objetivo: manter CH 01..32 exatamente como baseline e corrigir flicker de AUX/FX Returns.

Hipotese implementada
- O flicker era provavelmente causado por contaminacao entre streams:
  - /meters/1 deve atualizar somente CH 01..32.
  - /meters/13 deve atualizar somente AUX 01..08 e FX Return 01..08.
- Antes, o handler de /meters/1 iterava todos os listeners, incluindo AUX/FX IDs 33..48.

Implementacao
- Criado meterStreamRouting com:
  - isInputChannelMeterId
  - isAuxFxMeterId
  - getMeterStreamForChannelId
  - decodeMeterStreamBlobForChannel
  - dispatchMeterStreamBlob
- useMeterSubscription agora:
  - roteia /meters/1 somente para IDs 1..32.
  - roteia /meters/13 somente para IDs 33..48.
  - mantem request inicial e renew por familia de listener.
  - preserva METER_RENEW_INTERVAL_MS=8000.
  - preserva METER_REQUEST_THROTTLE_MS=1000.
- Nenhuma alteracao foi feita em ChannelVuMeter, escala visual, cores, segmentos, fader, mute, pan, presets ou BusGroups.
- /meters/3 nao foi implementado, pois deve permanecer fallback dependente de evidencia em console real.
