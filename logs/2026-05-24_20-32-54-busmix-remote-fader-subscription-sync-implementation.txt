BusMix remote fader subscription sync implementation
Timestamp: 2026-05-24_20-32-54

Implemented
-----------
- Added X32 scalar subscription protocol helpers/constants in X32Protocol:
  - /subscribe
  - /renew
  - /unsubscribe
  - default scalar subscription time factor
  - default scalar subscription renew interval
- Added OscClient.subscribeScalarValue(...):
  - registers an exact-address local listener;
  - sends /subscribe with the fader address and time factor;
  - ref-counts duplicate subscriptions by address;
  - renews before the 10s X32 timeout;
  - sends /unsubscribe when the last listener is removed;
  - clears managed timers on disconnect.
- Added BusMixService.subscribeChannelLevelUpdates(...):
  - subscribes to source send-level paths for CH/AUX/FX;
  - clamps incoming values;
  - does not send fader writes;
  - keeps /ch/17/mix/fader separate from /ch/17/mix/{bus}/level.
- Added useBusMixRemoteFaderSubscription:
  - subscribes only visible BusMix channels;
  - routes incoming levels into useBusMix remote reconciliation;
  - avoids React state updates per packet;
  - reports subscription health through callbacks/refs.
- Wired BusMixScreen.visibleChannelIds into useBusMix.
- Removed BusMix's old all-channel level listener from the general realtime effect to avoid duplicate level processing for visible subscribed faders.
- Extended realtime health refs with fader subscription diagnostics.
